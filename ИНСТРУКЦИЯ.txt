ОК — музыка, версия 10.63.2.5

Установка OrangeMonkey (Chrome, Windows):
1. Откройте страницу расширения:
   https://chromewebstore.google.com/detail/orangemonkey/ekmeppjgajofkpiofbebgcbohbmfldaf
2. Нажмите «Установить» / Add to Chrome и подтвердите установку расширения.
3. Через значок пазла в Chrome закрепите OrangeMonkey булавкой.
4. Откройте chrome://extensions/ → OrangeMonkey → «Подробнее».
5. Включите «Разрешить пользовательские скрипты» / Allow User Scripts.
   В Chrome до версии 138 для этого использовался «Режим разработчика».
6. Правой кнопкой по значку OrangeMonkey → «Параметры» / Options → My scripts.
   Если расширение уже установлено, проверьте его включение и разрешение
   запуска пользовательских скриптов; переустановка не требуется.

Установка: замените прежний локальный SaveFrom в OrangeMonkey файлом
savefrom-ok-batch.user.js. Не оставляйте две версии включёнными.
Обновите страницу ОК. Панель показывает «v5».

До песни «Колосок» (ALEKS ATAMAN, FINIK):
1. Откройте нужный список «Моя музыка».
2. Укажите «С песни». 1 означает начало списка.
3. Название «Колосок» и исполнитель уже заполнены.
4. Нажмите «Собрать и выбрать до песни».
5. Дождитесь сообщения о найденной песне и числе выбранных треков.
6. Нажмите «Скачать выбранные».
Конечная песня включается. При отсутствии песни загрузка не запускается.
Если есть несколько одинаковых названий и исполнителей, выбирается первое
совпадение. Для точного выбора используйте галочки в собранном списке.

«Скачать всё» прокручивает список с начала и затем отправляет найденные песни
браузеру. После восьми секунд без новых строк внизу автосбор завершается.
Это эвристика, а не подтверждение полноты: сравните число со счётчиком ОК.
Не переключайте сборники и не меняйте сортировку во время сбора или загрузки.

Галочки доступны возле распознанных строк ОК и в раскрывающемся списке панели.
«Выбрать диапазон» заменяет текущий выбор указанным диапазоном.
«Автосбор» только собирает список. Сбор с начала обновляет порядок песен.

«Пауза» приостанавливает автопрокрутку и отправку новых файлов браузеру.
«Стоп» сохраняет остаток очереди/позицию. Уже переданные Chrome файлы эти
кнопки не отменяют. После перезагрузки нажмите «Продолжить очередь / сбор».
Собранный список, выбор, история и настройки хранятся в хранилище менеджера
скриптов отдельно для адреса страницы. Прямые ссылки на аудио не сохраняются.

Пропуск повторов основан на ID песни и истории передач новой версии.
Старые версии историю не сохраняли, их загрузки автоматически не распознаются.
Передача браузеру не гарантирует сохранения файла. Проверяйте Ctrl+J.
Для повторной загрузки после ошибки Chrome снимите «Пропускать переданные
браузеру» и выберите нужные треки. При перезагрузке непосредственно во время
передачи неопределённая запись помечается в отчёте и пропускается как повтор.

Интервал между передачами: от 0,5 до 60 секунд. По умолчанию 1,5 секунды.
Ошибки получения ссылок фиксируются отдельно по ID и названию песни;
очередь продолжает работу. «Скачать отчёт» сохраняет JSON с составом списка,
историей передач и ошибками. Отчёт не содержит прямых аудиоссылок.

Проверено в автоматических тестах с моделированием страницы и OrangeMonkey:
автосбор виртуального списка, конечная песня включительно, галочки,
пропуск повторов, пауза, остановка, восстановление очереди, таймауты,
отчёт об ошибках конкретных песен. Полный запуск v5 на реальном аккаунте
пока не проверен. Способ передачи GM_download без событий использует
ранее подтверждённый пользователем рабочий вызов.
